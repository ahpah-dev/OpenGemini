Get started

You need Node.js 18+. Add Ollama if you want a local model.

# clone and install
git clone https://github.com/ahpah-dev/OpenGemini.git
cd OpenGemini
npm install

# optional: pull a local model
ollama pull qwen3:4b

# launch (opens http://localhost:3456)
npm start
